Official Problem Statement (From Course PDF - Page 2)

Scenario 2: Student Project and Skill Tracking System

Register No.: 2, 32, 62, 92, L2
Problem Statement

“The department wants to maintain records of student mini-projects, technical skills, programming languages, project milestones, and assessment results. Currently, this information is scattered across spreadsheets, making it difficult to monitor project progress and identify common skill gaps. Develop a Student Project and Skill Tracking System that stores project details, monitors progress, and analyzes students' skills and project completion trends.”

Functional Requirements (Exact from PDF Specification)
1
Maintain student details and technical skills.

Fulfilled in students & student_skills tables + Java DAO

2
Register individual student projects with titles, domains, descriptions, and technologies used.

Fulfilled in projects table + Java ProjectDAO

3
Record project milestones, submission dates, and completion status.

Fulfilled in milestones table + delay trigger

4
Maintain evaluation marks for defined project components.

Fulfilled in evaluations (Survey, Design, Impl, Test, Viva)

5
Generate reports on project progress and student skills.

Fulfilled via Java 8+ Streams API & groupingBy

6
Retrieve project and skill records from the database for analysis using Python.

Fulfilled in python/data_analysis.py via sqlite3

7
Visualize project completion rates, popular technology choices, and skill distribution.

Fulfilled with 6 high-res Seaborn/Matplotlib charts saved in visualizations/
